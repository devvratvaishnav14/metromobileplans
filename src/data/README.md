# Geographic data

## `metro-vancouver.municipalities.json`

Municipal boundary polygons for the main Metro Vancouver municipalities, used to
render the 3D map. Consume it through [`municipalities.ts`](./municipalities.ts),
never by importing the JSON directly — the `.ts` module adds types and helpers
and is where per-municipality logic (selection, labels, routing) will live.

### Source

| | |
|---|---|
| Dataset | **Municipalities – Legally Defined Administrative Areas of BC** (`WHSE_LEGAL_ADMIN_BOUNDARIES.ABMS_MUNICIPALITIES_SP`) |
| Publisher | Province of British Columbia — BC Data Catalogue |
| Page | https://catalogue.data.gov.bc.ca/dataset/municipalities-legally-defined-administrative-areas-of-bc |
| Licence | [Open Government Licence – British Columbia](https://www2.gov.bc.ca/gov/content/data/open-data/open-government-licence-bc) |
| Access | Province of BC public WFS (`openmaps.gov.bc.ca`), `GetFeature` as GeoJSON, `EPSG:4326`, filtered to `ADMIN_AREA_GROUP_NAME = 'Metro Vancouver Regional District'` |

Boundaries are the province's authoritative legal administrative areas — they are
**not** hand-drawn or approximated. The `meta` block in the JSON records the
source, licence, retrieval date and projection parameters.

### Processing

Generated by [`scripts/fetch-municipalities.py`](../../scripts/fetch-municipalities.py)
(standard library + `curl` only). To refresh:

```sh
python3 scripts/fetch-municipalities.py
```

The script:

1. filters the regional district's members down to the 17 selectable areas
   (the 15 named municipalities, with North Vancouver and Langley each split
   into their City and District/Township parts, as in the source data);
2. projects `lon/lat` → local metres (equirectangular about the data centroid);
3. simplifies every ring with Ramer–Douglas–Peucker (60 m tolerance) and drops
   sliver artefact parts (< 0.03 km²);
4. centres the result on its bounding-box midpoint and applies one uniform scale
   so the full east–west extent is `40` scene units.

### Shape

```jsonc
{
  "meta": { "source": "...", "projection": { ... }, "bounds": { "width": 40, "height": 27.87 }, ... },
  "municipalities": [
    {
      "id": "north-vancouver-district",       // stable kebab-case key
      "name": "District of North Vancouver",  // UI label
      "source_name": "The Corporation of the District of North Vancouver",
      "polygons": [                            // 1+ parts (islands / detached areas)
        { "outer": [[x, y], ...], "holes": [[[x, y], ...]] }
      ]
    }
  ]
}
```

Coordinates are 2D map-plane points in scene units: `+x` = East, `+y` = North,
origin at the centre of the Metro Vancouver extent. The renderer
([`scene/Municipalities.tsx`](../scene/Municipalities.tsx)) lays this plane flat
and extrudes it upward.
